# Contexto
    Este repositório tem exercícios:
    Forca -> sorteia palavra de uma lista, mostra _ _ _, conta erros, avisa vitória ou derrota e pergunta se quer jogar de novo
    Conversor -> menu com pelo menos 3 tipos (ex.: km↔milhas, °C↔°F, real↔dólar com cotação fixa), uma função por conversão, trata entrada inválida
    Gerador de senhas -> pergunta o tamanho e os tipos de caractere (maiúsculas, números, símbolos), valida a entrada e gera a senha

# Padrões
   - Python 3, só biblioteca padrão.
   - Nomes de variáveis e funções em português, snake_case.
   - Cada projeto roda com: python pasta/arquivo.py
   - Cada exercicio terá uma branch separada
